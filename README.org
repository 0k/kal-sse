#+TITLE: kal-sse

Resilient Server-Sent Events: snapshot + cursor data channels with
gap-free reconnect.

* What it is

A *data channel* pairs a REST snapshot with an SSE update stream:

- the REST snapshot establishes the client's starting position — a
  monotonic cursor index =N= on the channel;
- the SSE stream then delivers every update after =N=, in order, each
  tagged with its own index so the client always knows where it is.

A client identifies itself to one or more channel with a *subscription id*
(=sub_id=) — one per logical subscription to one data flow.

* Why "resilient"

The cursor is *delivery-driven*: sending the =N -> N+1= event /is/ the
state transfer. Once the server has emitted that event to a
subscription, the subscription is authoritatively at =N+1= — no ack,
no heartbeat, no re-snapshot. This lets the server retain exactly the
events some live subscription might still need, and no more.

When a subscription's stream drops, the server keeps its handle for a
TTL. A reconnect with the same =sub_id= and the cursor the client
still holds (=?since=N=) resumes *gap-free*: the server replays =N+1..=
then attaches to live. Only when =N= has fallen out of the retained
buffer does the server answer =409 expired_cursor=, and the client
re-snapshots.

* Layers

- =core= — framework-agnostic. The =EventLog<E>= data structure, the
  subscription registry, cursor advancement, compaction, and the
  =ExpiredCursor= error. No HTTP, no axum, no =serde=.
- =axum= (feature =axum=) — a thin adapter turning a channel
  subscription into an =axum= SSE response: =?since= / =Last-Event-ID=
  parsing, =409 expired_cursor=, the =id:= field, =x-snapshot-index=,
  and keep-alive.

The core never depends on the adapter; the adapter is opt-in so the
data structure stays reusable outside any web framework.

* Usage

Add to =Cargo.toml=:

#+begin_src toml
[dependencies]
kal-sse = { version = "0.1", features = ["axum"] }
#+end_src

Server side: hold an =Arc<Mutex<EventLog<E>>>= per channel, =append=
events to it, =compact= on a periodic tick, and serve the SSE endpoint
through =kal_sse::axum::sse_response=. The REST snapshot endpoint hands
out =EventLog::last_index= via the =x-snapshot-index= header.
